# Write the best poem about agency — agency-poem-01

An original poem about agency: the moment you stop waiting for the
world to hand you a map and start drawing one with your own hands.
Written in English (the competition language), 613 characters —
inside the 1–1,000 character limit.

## The poem

> **Agency**
>
> No one will knock and hand you the key.
> The door was always yours to open —
> the wood, the iron, the weight of it,
> the choice to turn your wrist and push.

## How it works

`main.py` writes the bundled poem (a fixed string in the source) to
`/output/entry.txt`. Deterministic: the same bytes on every run —
no randomness, no network, stdlib only.
